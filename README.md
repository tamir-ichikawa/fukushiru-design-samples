C案は比較対象から外しています。サイト名は「フクシル」。ロゴ上の歯車状の飾りはありません。

## サンプルの範囲

- 掲載する資料名・件数・書類画像は、すべて架空の表示見本です。
- トップから4つのカテゴリーへ移動し、検索・絞り込み・並び替え・ページ送りを試せます。
- 資料を開くと表示見本を表示します。実ファイルの取得や動画再生は未接続です。
- ブックマークはメモリ内のみで、再読み込みするとリセットされます。
- 認証・アカウント・データベース・本番API・本番ストレージへの接続はありません。
- このリポジトリは、本番システムのソース・原本・参考画像・運用データを含みません。
- オリジナルのAI生成イラストを使用しています。

## PCでの確認

試験用サンプルのため、PCでの確認を対象としています。スマホ向けの追加調整は行っていません。

## ローカルで開く

ダウンロード後、`index.html` をブラウザで開いてください。ビルドや外部ライブラリは不要です。

HTTPで確認する場合は、このフォルダで `python -m http.server 8742 --bind 127.0.0.1` を実行し、表示されたローカルURLを開きます。

## 公開方法

GitHub Pagesで `main` ブランチのルートを公開します。独自ドメインや他の本番サービスは使用しません。
